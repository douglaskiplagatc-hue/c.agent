# Project Memory

## Purpose

This memory contains persistent information about the project being worked on.

## Agent Rules

- Inspect existing code before making changes.
- Do not invent files, functions, models, or dependencies.
- Preserve the existing architecture unless a change is explicitly required.
- Prefer small, targeted changes.
- Verify changes after editing.
- Never expose or modify secrets.
- Never modify files outside the allowed workspace.

## Development Workflow

1. Understand the request.
2. Inspect the project.
3. Search relevant code.
4. Read affected files.
5. Plan the change.
6. Modify the code.
7. Run verification.
8. Analyze errors.
9. Fix problems.
10. Verify again.
